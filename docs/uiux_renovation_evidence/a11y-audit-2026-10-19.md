## The defect this pass found

The browser sweep failed on the unmodified tree: `/forgot` in dark mode
(`.primary`, serious `color-contrast`). Root cause was a token-layer gap, not a
one-off: every accent hue flips lightness between themes, and the foreground on
those accents was hard-coded `#fff` (measured 1.4:1-2.7:1 in dark mode) on the
primary buttons, the skip link, the impersonation banner, the user chat bubble,
active chips and the quick-action icons. Fixed with `--on-brand`, `--on-teal`,
`--on-ai`, `--on-danger` (white in light; hue-matched dark inks in dark,
6.0:1-10.6:1) in `src/styles.css`. The jsdom axe suite could never see this —
it disables colour-contrast because jsdom has no layout.

## Performance

Lighthouse before/after is recorded in `E-R2-g2-001` and `E-R2-g2-004`, and the
controlled font-preload A/B in `E-R2-g2-005`. The full numbers, including what
they do and do not prove, are in `.audit/handoffs/workflows-g2.md` § 8. In one
line: the first-paint fonts are now discovered ~800 ms earlier (reproducible),
the LCP delta on this contended host is inside the noise, and the perf/LCP
budgets are therefore still open on 5 of the 6 public routes.

## Reproducing

```bash
# browser a11y sweep (starts its own API + preview, seeds all five roles)
cd apps/web && npx playwright test e2e/axe.spec.ts e2e/keyboard.spec.ts

# visual + ARIA baselines (reviewed; regenerate only with --update-snapshots)
cd apps/web && npx playwright test e2e/visual.spec.ts e2e/screen-reader.spec.ts

# CPU-throttled traces
cd apps/web && npx playwright test e2e/perf.spec.ts

# budgets and the token ratchet
cd apps/web && npm run build && npx size-limit
python scripts/scan_design_tokens.py --check
```

Browsers: Chromium (Playwright 1.63.0). Lighthouse: `@lhci/cli` 0.15.1 with
Chrome/Edge, mobile form factor, simulated throttling.
