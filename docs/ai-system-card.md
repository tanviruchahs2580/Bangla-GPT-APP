## 1. Intended use

- **Product**: a NCTB-curriculum-grounded, Bangla-first AI tutor for school
  students. Students ask curriculum questions in Bangla, Banglish or
  English code-switching; the tutor answers from the NCTB curriculum corpus
  and cites book/chapter/section/page (`docs/RAG_ARCHITECTURE.md`,
  "Implemented architecture").
- **Intended users**: students of classes 6–10 (secondary) and 11–12 (HSC)
  when the corresponding corpus subset is served, plus teachers and guardians
  who see progress through their own authenticated dashboards. The product
  holds children's personal data by design (`SECURITY.md`, opening section).
- **Intended environment**: a single-school or small multi-school deployment
  (two services per ADR-0007). The bundled sample corpus serves classes 6–10
  only.
- **Out-of-scope uses**, stated in the product's own copy and kept out of the
  model's reach:
  - It is **not a replacement for a teacher** — the Bangla UI copy says
    "AI সহকারী হিসেবে আপনার সামর্থ্য বাড়ায় — কখনো শিক্ষকের বিকল্প নয়"
    (`apps/web/src/i18n.ts:597`).
  - It is **not an emergency or medical service**. Self-harm and other
    harmful categories receive a supportive refusal that directs the student
    to a trusted adult, guardian, teacher or local emergency services — with
    no invented helpline number (`apps/api/src/bangla_gpt_api/services/safety.py:18`,
    removal recorded in `a70f5be`).
  - It has **no action surface**: the model cannot write to the database,
    send messages, or call tools; only the application may act on a user
    request (`docs/threat-model.md` LLM06 row).

## 5. Known failure modes

From measured tests and reproduced QA findings — not hypotheticals:

1. **Refusal when retrieval misses.** If IDF-weighted coverage of the
   question's content terms falls below 0.5, or ≥ 2 content terms are absent
   from the corpus, the tutor abstains with a fixed refusal message instead of
   answering (`apps/api/src/bangla_gpt_api/services/tutor.py:272`, refusal at
   `:728`). This is the designed safe failure, and it is metered
   (`bgpt_rag_gate_refusals_total`).
2. **Post-generation citation check failure.** The answer's stem coverage
   against the evidence must reach 0.25 (`services/tutor.py:652`); a failed
   check marks `citation_verified=false`, logs a warning and increments
   `bgpt_rag_citation_checks_total`. On both streaming and non-streaming a
   refusal carries `citation_verified=None`.
3. **Empty/mis-set corpus.** Without `NCTB_CORPUS_DIR` the API serves the
   78-chunk sample (classes 6–10) with a boot warning and a metric label —
   never silently — and `/ready` reports degraded when the index is absent
   (`docs/RAG_ARCHITECTURE.md` "Corpus flow", "Runtime execution notes").
4. **Extraction artefacts.** Legacy Bijoy conversion leaves rare conjunct
   reorderings (`কার্যক্রম` as `কাযর্ক্রম`); affected content stays
   retrievable at reduced lexical precision (`docs/NCTB_DATA_PIPELINE.md` §3).
   PUA residue is stripped and legacy-Bijoy chunks dropped at load.
5. **A student's older assignment can be hidden** by the platform-wide window
   in `/assignments/mine`; reproduced and deliberately unfixed pending an
   indexable membership column (`docs/qa/QA_REPORT_2026-10-17.md` §6).
6. **Check-then-insert races** on unique-keyed progress rows can produce a 500
   after the business write committed (same section).
7. **Safety layer is keyword-regex based** (deterministic, auditable,
   zero-latency) and therefore breadth-limited; an LLM classifier is a
   documented future complement (`apps/api/src/bangla_gpt_api/services/safety.py`
   module docstring; deferred finding AUD-A2-04).
8. **Mock mode in production is refused at boot** (`enforce_production_safety`,
   `apps/api/src/bangla_gpt_api/main.py:72`), so a deployment cannot
   accidentally serve mock answers with production data — it fails closed.

## 7. Update process

| Change type | Procedure that exists today |
|---|---|
| Application change | Conventional Commits; squashed PRs; CI (`ci.yml`) gates lint, types, tests on SQLite + PostgreSQL, web build/tests, Docker smoke, `pip-audit` / `npm audit`, gitleaks full-history scan, pre-commit on all files; CHANGELOG is generated from commits and CI fails on an unlisted commit (`apps/api/scripts/check_changelog.py`) |
| Retrieval/AI-quality change | Regenerate the committed eval artifacts **in the same change**; the eval gate fails on a > 2 pp drop against `apps/api/eval/baseline_v2.json` (`.github/workflows/eval-gate.yml:51`); retrieval edits regenerate `data/nctb/retrieval_eval.json` with the diff reviewed (`docs/RAG_ARCHITECTURE.md` "Measured baseline" preamble) |
| Corpus change | Re-run `apps/api/scripts/build_nctb_corpus.py` (idempotent acquisition, hash-checked); the per-chunk QA gate can fail the build; committed QC files are updated in the same change (`docs/NCTB_DATA_PIPELINE.md` §2, §4, §6) |
| Provider/model change | Provider abstraction (ADR-0002) + config only; the boot guard refuses mock in production; any real-model rollout requires a live evaluation run — currently BLOCKED pending the owner's key (`.audit/reports/FINAL.md` §11.1) |
| Model/provider behaviour change detection | `bgpt_rag_gate_outcomes_total`, `bgpt_rag_gate_refusals_total`, `bgpt_rag_citation_checks_total` metrics + `HighRAGRefusalRate` / `RAGCitationCheckFailures` alerts (`deploy/prometheus/alerts.yml`) |
| Release | Tags drive `release.yml`; the workflow refuses to build a tag whose commit has no successful CI run (`.github/workflows/release.yml:83`); GHCR image tagged by version only (no `:latest`). Zero GitHub Releases are published today (owner action, AUD-JK-06) |
| Safety copy change | Reviewed as product copy; the helpline was removed rather than guessed and may only return after verification (`apps/api/src/bangla_gpt_api/services/safety.py:14`) |

Versioning of this application: the version is currently hardcoded in several
files (audit finding AUD-JK-12); `scripts/check_version.py` (added with this
card, wired in the CI handoff) now asserts they agree so the card's "applies
to" statement stays true.
